# 生词现场拆解流程：先找动作 → 再看方向 → 组合词义 → 校验

## R — 原文 (Reading)

> "下次再碰到生词，先找动作，再看方向。最后三道题都是没讲过的词，你自己拆。"
>
> — 视频字幕，收尾（L1000-1003, L1030-1032）

## I — 方法论骨架 (Interpretation)

这是面对没见过的生词时的通用推理顺序，也是全篇最能迁移到任意新词的能力。作者把它压缩成一句口诀："先找动作，再看方向"。具体是：第一步，在生词里定位 25 个动作根之一，唤起它的动作画面；第二步，读出前缀的方向；第三步，把动作与方向组合，推出一个初步词义；第四步，用是否讲过的新闻/同理词校验，或用"没讲过的词现场拆"来自测。作者用三个课后题（intercept=半路拿走→拦截、deport=搬走→驱逐出境、convene=来到一起→召集开会）演示：即使这个词从没见过，只要它在"动作根 + 方向"系统内，就能现场推导出来。它和核心模型的区别是：核心模型讲"词由什么构成"（静态结构），本流程讲"遇到生词先做什么后做什么"（动态操作步骤）。

## A1 — 视频中的应用 (Past Application)

### 案例 1: 自测题 deport（驱逐出境）
- **问题**: deport 没讲过，怎么现场拆？
- **方法论的使用**: 先找动作——port=扛/搬；再看方向——de=离开/去掉；组合——"搬走（离开本地）"。
- **结论**: deport = 把人搬走/驱逐出境。
- **结果**: 没见过的词靠流程现场推出，验证了可迁移性。

### 案例 2: 自测题 convene（召集）
- **问题**: convene 没讲过，怎么拆？
- **方法论的使用**: 先找动作——ven=来；再看方向——con=一起；组合——"来到一起"。
- **结论**: convene = 来到一起 = 召集、开会。
- **结果**: 同上，流程对新词有效。

### 案例 3: 自测题 intercept（拦截）
- **问题**: intercept 没讲过，怎么拆？
- **方法论的使用**: 先找动作——cept=拿；再看方向——inter=中间；组合——"半路拿走"。
- **结论**: intercept = 半路拿走 = 拦截。
- **结果**: 三道自测题全部可由流程推出，构成方法论有效性的演示。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 阅读/考试中遇到没见过的英语单词，想现场推断含义而不是查完就忘。
2. 想知道"遇到生词该怎么拆/怎么猜词"的方法。
3. 想自测自己是否真的掌握了拆词法（用没讲过的词练手）。
4. 在问"这个词能不能拆出来/我拆的对不对"。

### 语言信号 (中英双写)
- "遇到生词怎么办 / 这个词没见过怎么猜 / 怎么现场拆词"
- "先找动作再看方向 / 拆词步骤 / 怎么自己推导词义"
- "how to guess unknown word / break down unfamiliar word / decode new word steps"

### 与相邻 skill 的区分
- 与 `word-decoding-core`（核心模型）: 本卡是**操作顺序**；core 卡是**构成原理**。用户问"怎么拆一个生词"用本卡；问"这个词为什么是这个意思/词根法是什么"用 core 卡。
- 与靠上下文猜词: 本流程靠**构词结构**（动作+方向）推导，不依赖上下文语义猜测。

## E — 可执行步骤 (Execution)

当被激活后，agent 按以下顺序执行：

1. **扫描词形，定位动作根**：在生词中匹配 25 个动作根之一（ject/port/fer/mit/duc/fact/struct/form/press/plic/tract/pend/vert/rupt/clud/cept/tain/pos/tend/sist/ced/gress/ven/cur/spect）。完成标准：找到一个根并说出其动作画面。判停：找不到任何根 → 转 B 段（不强行拆）。
2. **识别前缀方向**：拆出前缀，读成一个方向词。完成标准：前缀→方向映射明确。判停：无前缀（词根本身就是词义）→ 直接给出根的动作义。
3. **组合推出初步词义**：把"方向 + 动作"拼成一句中文释义。完成标准：能解释"为什么是这个意思"。
4. **校验**：用一个已知的含同根/同前缀的词做交叉验证，或检查组合是否符合常见词义。完成标准：词义合理且能自圆其说；若牵强 → 标注存疑，建议查词典。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 词不在"动作根 + 方向"系统内（希腊根、单音节基础词、拟声词、外来词）。
- 只需知道读音/拼写/用法，不需要理解词义来源时。
- 需要权威释义的场景（考试标准答案、法律/医学术语）——推导仅供理解辅助，以词典为准。

### 视频暗示的失败模式
- 只找方向不找动作，或只找动作不读方向 → 组合不完整，推出错误词义。
- 对不在系统内的词强行套流程 → 编造出牵强的动作故事。

### 作者盲点 / 时代局限
- "先找动作再看方向"对词根多义、语义漂移大的词（如 object 物体/反对）会给出片面结果，作者未强调这一点。
- 推导出的词义是"合理猜测"，不等于规范释义，需校验环节兜底。

### 容易混淆的邻近方法论
- 语境猜词法（靠上下文和词性推断）≠ 本流程（靠构词结构推导）；两者可互补，但本 skill 只负责构词路径。
