# 词族批量扩展与记忆减负

## R — 原文 (Reading)

> "你已经把 191 个词从头拆到了尾，一个都没死记，你记住的是 25 个动作。下次再碰到生词先找动作再看方向。"
>
> — 视频字幕，收尾（L997-999, L1025-1032）

## I — 方法论骨架 (Interpretation)

与其把 191 个词当 191 个孤立条目逐个背，不如把它们看成"25 个动作根 × 一张方向前缀表"的组合矩阵：以某个动作根为轴，依次配上不同方向前缀，就能批量派生并复习一整族词。ject 配 re/in/e/pro/ob 得 reject/inject/eject/project/object；port 配 im/ex/sub/re 得 import/export/support/report；mit 配 sub/pro/per/ad/trans/e 得 submit/promise/permit/admit/transmit/emit。记一个根等于记一串词，记忆对象从"191 个词"压缩到"25 个动作 + 若干方向"，认知负荷大幅下降。这是把核心模型规模化为复习/记忆策略的能力：它不负责理解单个词（那是 core/flow 的事），而负责"如何按族成批地扩展和巩固词汇量"。

## A1 — 视频中的应用 (Past Application)

### 案例 1: port 词族的批量扩展
- **问题**: 如何一次记住一大把含 port 的词？
- **方法论的使用**: 以 port(扛) 为轴，配 8 个方向：im(里)/ex(外)/sub(下)/re(回)/trans(跨)/e 等。
- **结论**: import/export/support/report/transport/portable/passport/portfolio 一族全部由"方向 + 扛"推出。
- **结果**: 8 词成串记忆，而非 8 个孤立条目。

### 案例 2: mit 词族的批量扩展
- **问题**: mit 家族词多且易混，如何成批掌握？
- **方法论的使用**: 以 mit(送) 为轴配方向：sub(下)/pro(前)/per(穿过)/ad(朝)/trans(跨)/e(外)/dis(散)。
- **结论**: submit/promise/permit/admit/transmit/emit/dismiss/mission 一族推出。
- **结果**: 一族 9 词由一个动作根统摄。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 想扩大词汇量、高效记一串词，而不是逐个背单词表。
2. 想复习某个词根家族（"把 spect/ject/port 的词都列出来"）。
3. 在问"怎么按词根记单词 / 怎么批量记单词 / 词根怎么串起来记"。
4. 想检验自己某根掌握得全不全（"spect 家族我都知道哪些词"）。

### 语言信号 (中英双写)
- "怎么批量记单词 / 词根串起来记 / 把同一个词根的词列出来"
- "复习词根家族 / 一节课记一串词 / 记一个根记一串"
- "word family / list words with this root / learn words by root / group vocabulary"

### 与相邻 skill 的区分
- 与 `word-decoding-core`（核心模型）: core 讲"词 = 动作 + 方向"的原理；本卡讲如何用这个原理**批量组织记忆与复习**。用户问"这词啥意思"用 core；问"怎么成批记/列一族词"用本卡。
- 与 `word-decode-flow`（拆解流程）: flow 面向单个生词的即时推导；本卡面向**一批词的存储与复习**。

## E — 可执行步骤 (Execution)

1. **确定轴根**：明确要扩展/复习哪个动作根（用户指定，或按目标词汇表选高频根）。完成标准：选定一个根并唤起其动作画面。
2. **列举方向**：调用方向前缀表（re/in/ex/pro/sub/de/con/dis/trans/per/inter/ad/pre/retro/sus…），逐个配到轴根上。完成标准：覆盖主要方向前缀。
3. **批量生成词族**：对每个"方向 + 根"组合，写出对应单词和"方向+动作"释义。完成标准：产出一族词（通常 5–10 个），每个都有推导式释义。
4. **减负对照**：点明"记 1 个根 + N 个方向 = N 个词"，强化记忆经济性。完成标准：用户看到批量收益。
5. **判停**：若某些组合不产生真实单词（构词有例外），跳过并注明，不强行造词。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 用户只想理解/确认单个词——用 core/flow 卡，不必展开整族。
- 目标词不在"拉丁动作根 + 方向"系统内（希腊根、基础词）——本表覆盖不到。
- 需要词的精确用法、搭配、语域时——批量推导只解决"记住/理解"，不解决"会用"。

### 视频暗示的失败模式
- 逐词孤立背 → 退回到 191 个条目的高负荷路径，违背减负初衷。
- 为凑词族强行拼出不存在的组合 → 造词，误导记忆。

### 作者盲点 / 时代局限
- "记一个根记一串词"假设组合都能产出常用词，实际构词有大量例外和不规则（如某些根配某些前缀无对应词）。
- 批量记词解决"进入长期记忆的入口"，不等于能正确拼写和在语境中使用。

### 容易混淆的邻近方法论
- 按字母顺序/主题分类背单词 ≠ 本卡（按动作根 × 方向矩阵聚类）。
