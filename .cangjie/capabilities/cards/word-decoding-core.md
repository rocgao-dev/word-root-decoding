# 拆词核心模型：词 = 动作词根 + 方向前缀

## R — 原文 (Reading)

> "每个词是一个词根一个动作，每条线是一个前缀一个方向。25 个动作，191 个词，全在这一张图上。你记住的是 25 个动作。"
>
> — 视频字幕，开篇总纲（L2-9）与收尾（L997-999）

## I — 方法论骨架 (Interpretation)

把英语常用词当成两块积木拼成的：「一个具象动作（词根）+ 一个方向（前缀）」。词根不是要背的抽象释义，而是一个能在脑子里演出来的身体动作——扔（ject）、扛（port）、带（fer）、送（mit）、引（duc）、做（fact）、垒（struct）、压（press）、折（plic）、拉（tract）、挂（pend）、转（vert）、破（rupt）、关（clud）、拿（cept）、握（tain）、放（pos）、伸（tend）、站（sist）、走（ced）、迈（gress）、来（ven）、跑（cur）、看（spect）等 25 个。前缀不是零散小部件，而是统一读作一个方向——回（re）、里（in/im）、外（ex）、前（pro）、下（sub/de）、一起（con）、分开（dis）、穿过（trans/per）、中间（inter）等。词义就是"这个动作被这个方向修饰后"的结果：re(回)+ject(扔)=扔回去=拒绝，ex(外)+port(扛)=扛出去=出口。掌握 25 个动作和一张方向表，就能推导大量高频词，而不是逐词死记。

## A1 — 视频中的应用 (Past Application)

### 案例 1: ject（扔，一下离手）
- **问题**: 一组含 ject 的词意思各异，如何统一理解？
- **方法论的使用**: 先把 ject 锚定为"投石机一甩、石头离手飞出去就不管"的动作画面，再逐个配方向。
- **结论**: re(回)+扔=扔回去→reject 拒绝；in(里)+扔=扔进身体→inject 注射；e(外)+扔=eject 弹出；pro(前)+扔=把计划往前扔→project 项目；ob(迎面)+扔=object 物体/反对。
- **结果**: 7 个词由一个动作 + 方向批量推出，无需逐词背。

### 案例 2: port（扛，一路带着走）
- **问题**: import/export/support/report 如何一次记住？
- **方法论的使用**: 把 port 锚定为"扛着货一路走"，与 ject 的"一下离手"对照，再配方向。
- **结论**: im(里)+扛=import 进口；ex(外)+扛=export 出口；sub(下)+扛=从下面扛住→support 支持；re(回)+扛=把消息带回来→report 报告。
- **结果**: 8 个 port 词族一次性成串推出。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 看到含常见词根/前缀的生词，想理解它为什么是这个意思、想"拆开看"。
2. 在问"词根词缀怎么记/词根法是什么/这个词怎么拆"。
3. 想一次性搞懂一族词（reject/inject/eject…）而不是逐个背。
4. 想判断某个拆词结果对不对、某个词能不能这么拆。

### 语言信号 (中英双写)
- "这个词怎么拆 / 拆开是什么意思 / 词根词缀"
- "reject 为什么是拒绝 / 这个词根是什么意思"
- "word root / prefix / why does this word mean / break down this word"
- "怎么快速记一串单词 / 词根记忆法"

### 与相邻 skill 的区分
- 与 `word-decode-flow`（生词拆解流程）: 本卡是**静态模型**（词由什么构成），flow 卡是**动态步骤**（遇到生词先做什么后做什么）。用户问"这个词为什么这意思"用本卡；问"遇到生词怎么办"用 flow 卡。
- 与 `root-feel-discrimination`（手感辨析）: 本卡讲词根+方向的组合机制；手感卡讲**近义动作根之间**的细微区别。用户问"ject 和 port 啥区别"用手感卡。

## E — 可执行步骤 (Execution)

1. **定位词根动作**：在词中找出 25 个动作根之一，先唤起它的身体动作画面（不是中文释义）。完成标准：能用自己的话描述这个动作过程（如"扛着东西一路走"）。
2. **读出前缀方向**：找出前缀，把它读成一个方向（回/里/外/前/下/一起/分开…）。完成标准：前缀被翻译为一个方向词，而非字典多义项。
3. **组合推义**：把"方向 + 动作"组合，推出词义。完成标准：能说出"因为X方向作用于Y动作，所以是Z义"。
4. **判停/校验**：若该词根不在 25 个动作内、或动作感明显不透明（如纯描述词、拟声词），停止强行拆解，转用语境/词典（见 B 段）。若组合结果牵强，标注为"存疑，需查证"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 希腊词根词（photo/tele/geo…）、单音节基础词、拟声词、不透明高频词——本模型只覆盖拉丁动作根 + 前缀路径。
- 需要精确学术词源时——这是助记法，不是严格词源学。
- 判断搭配、语域、拼写用法——本模型只解决"理解与记忆入口"，不等于会用。

### 视频暗示的失败模式
- 把词根当抽象中文释义背 → 退回死记硬背，失去推导能力。
- 把一个前缀按字典多义项展开 → 破坏"一前缀=一方向"的极简承诺，增加负担。
- 强行给不透明的词套动作故事（如 effect "效果"、object "物体"）→ 动作感牵强，反而增加认知负担。

### 作者盲点 / 时代局限
- 把 con(一起)、per(到底)、ad(朝着) 等抽象引申义一律解释为"方向"是一种简化，对部分词不精确。
- 字幕为语音转写，含同音错字，词根/前缀拼写需以标准英语为准。

### 容易混淆的邻近方法论
- 学院派词源词根词缀法（按拉丁/希腊词源精确分解）≠ 本模型（按身体动作 + 方向助记推导）。
