## 1. 结构 (Structural)

### 类型
方法论 + 实操教学（英语词根词缀记忆法），带少量现场演示与课后自测题。

### 一句话主旨
把每一个英语常用词拆成「一个具象动作（词根）+ 一个方向（前缀）」，用 25 个动作和若干方向前缀推导出 191 个高频词的意思，从而做到"看一眼就能拆开"。

### 骨架 (主要论点及其关系)

1. **词 = 动作 + 方向**：每个词根是一个物理动作（ject=扔、port=扛着走、duc/duct=引、fact=做…），每个前缀是一个方向（re=回、in/im=里、ex=外、pro=前、sub=下…）。词义 = 动作被方向修饰后的结果。（核心模型）
2. **动作有"手感"差异，须精细区分**：如"扔(ject) 是一下离手、投出去就不管"，"port 是一路扛着走"，"fer 是带"，"mit 是送、放手让它去"，"duc 是引、一路领着走"。近义动作靠"手感"区分，不靠中文翻译。（对论点1的深化）
3. **同根成族，一词根带一串词**：ject→reject/inject/eject/project/object/adjective/trajectory；port→import/export/support/report/transport/portable/passport/portfolio。（论点1的规模化应用）
4. **遇到生词的通用拆解流程**："先找动作，再看方向" —— 先在词里定位 25 个动作之一，再读前缀方向，组合出词义；最后三道课后题用没讲过的词（intercept/deport/convene）让学习者现场拆。（方法论的迁移与验证）
5. **记忆负荷的承诺**：25 个动作 + 191 个高频词压在一张图上，记住的是 25 个动作而非 191 个孤立单词，下次遇到生词可现场推导。（价值主张 / 收尾）

**论点之间的关系**: 层层递进 —— 先给模型（1），再讲模型的精细处（2），再展示规模复用（3），再抽象成通用流程（4），最后给出收益（5）。

### 作者要解决的核心问题
英语常用词（700+）太多、死记硬背记不住；如何用一个很小的动作/方向组合系统，让学习者看到生词就能自行拆解、推导词义。

## 2. 解释 (Interpretive)

### 关键术语 (作者本人的用法)

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 动作（词根 / "磁根"，25 个） | 一个具象的物理动作画面，如扔、扛、带、送、引、做、垒、压、折、拉、挂、转、破、关、拿、握、放、伸、站、走、迈、来、跑、看 | 常识把词根当抽象词源单位；作者把它当成可想象的身体动作 |
| 方向（前缀 / "前坠"） | 动作的空间/逻辑指向：回(re)、里(in/im)、外(ex/e)、前(pro)、下(sub/de)、一起(con/com)、分开(dis)、穿过(per/trans)、中间(inter)、向上上来(ad)… | 常识把前缀当"改词义的小部件"；作者统一为"方向"一种语义 |
| 手感 / 动作差异 | 近义动作之间的细微区别：一下离手 vs 一路扛着走；带(跟着走) vs 送(放手让它去) vs 引(领着走) | 常识靠中文释义区分（都是"扔/带"）；作者靠动作过程的身体感区分 |
| 词族 | 同一动作词根 + 不同方向前缀派生出的一串词 | 常识按字母/主题记单词；作者按动作根聚类 |
| 拆词 | 看到生词时"先找动作、再看方向"的现场推导操作 | 常识的"猜词"靠上下文；作者靠构词结构 |

### 核心命题 (用自己的话)

1. 常用词不是随机的字母串，而是"动作 + 方向"的组合，因此可以像搭积木一样被拆解。
2. 词根要记住的不是中文释义，而是一个看得见的动作画面（投石机甩石头、人扛货一路走、铁钳夹起铜币…）。
3. 近义动作根（扔/扛/带/送/引、压/折、拉/挂、转/破、拿/握/放、走/迈/来/跑）的区别在动作过程，抓住"手感"就不会混。
4. 一个动作根配不同方向前缀，能批量生成一整族词，记一个根等于记一串词。
5. 遇到没学过的生词，走"先找动作 → 再看方向 → 组合词义"的流程即可现场推导，这是可迁移到任意新词的能力。

### 论证链
作者用"演示归纳法"：逐根给出一个动作意象 → 立刻用该根拼出 4–8 个真实单词并给出"动作+方向"的释义 → 覆盖 25 根/191 词 → 结尾用 3 个没讲过的词（intercept/deport/convene）让学习者现场套用流程，作为方法论有效的证据。

## 3. 批判 (Critical) ★

### 作者的时代局限
- 这是一套"教学助记法"而非严格的历史语言学；部分词根的"动作意象"是为好记而重新包装的，与词源学结论不完全一致（作者未声明这一点）。
- 字幕转写存在大量同音错字与口误（"磁根""扶窩""意识浓缩"等），原始材料的精确性本身有限。

### 作者的立场盲点
- 只覆盖"拉丁词根 + 前缀"这一条构词路径；希腊词根（photo、tele、geo…）、不透明的高频词、拟声词、单音节基础词不在射程内，但作者用"英语里 700 多个常用词"的措辞暗示覆盖面很广。
- 把"前缀"一律解释为"方向"，对 re-/in-/ex- 等空间义成立，但对 con-（一起）、per-（到底/穿过）、ad-（朝着）等抽象/引申义是简化。
- 忽略"动作根多义"现象：同一词根在不同词里动作感会漂移（如 cap/cept 的"拿/抓/容纳"）。

### 未被证明的假设
- 假设"具象动作画面"比"抽象释义/语境记忆"更易记、更快 —— 这对字形记忆型学习者未必成立，作者未给出对比证据。
- 假设"能拆开词义 = 能掌握该词" —— 拆词只解决理解/进入长期记忆的入口，不等于会用（搭配、语域、拼写仍要另学）。
- 假设 25 个动作 + 一批方向前缀的记忆成本低于 191 个词；对零基础学习者，先记这套系统本身也是负担。

### 最强反对意见
最强的反驳是"词根法的迁移率被高估"：英语常用词中真正符合"透明动作+方向"的可拆比例有限，大量词经过语义漂移后动作意象已不透明（如 "effect 效果""object 物体/反对" 的动作感很牵强）；强行套动作故事反而增加认知负担，不如高频词直接语境记忆 + 少量高产能词根（如 ject/spect/duc）重点掌握。

> **以上批判会直接成为下游 skill 的 Boundary (B) 字段来源**
